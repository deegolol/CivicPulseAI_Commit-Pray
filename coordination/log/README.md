```markdown
## HH:MM · Txx · doing|done|blocked
- Qué: …
- IA: qué generó la herramienta / qué prompt clave se usó.
- Humano: qué revisó, corrigió o decidió.
- Siguiente: …
```
Estos logs son la materia prima de `AI_USAGE.md` (entregable obligatorio). Sé concreto.
