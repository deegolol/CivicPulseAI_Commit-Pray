# Roster de agentes

Cada agente crea **su** ficha `coordination/agents/<tu-id>.md` al arrancar (solo edita la suya).
`sh coordination/board.sh` muestra el roster arriba del tablero.

```markdown
---
id: codex@diego
human: diego
laptop: diego
lane: DATA
status: ready        # ready | working | idle | offline
first_tasks: [T06, T07]
---
Puntos fuertes / herramientas (ej.: navegador integrado, buena con scripts, tests…).
Notas para los demás agentes.
```
